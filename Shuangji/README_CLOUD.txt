双机 Shuangji - 云服务器部署说明

【架构】
三个软件都安装并运行在同一台云服务器（Windows 云机）上。
用户不需要内网穿透。用户用云机的公网 IP / 域名访问。

【云机上启动】
1. 远程桌面登录云机
2. 管理员运行 START_ALL.bat（或依次开 01 → 03 → 02）
3. 云厂商安全组/防火墙放行入站：
   - 8088  TCP  用户网页控制台
   - 1080  TCP  Shadowrocket SOCKS5 代理
   （9100/9200 建议仅本机，不必对公网开放）

【用户怎么用】
1. 浏览器打开：http://云机公网IP:8088/
   例：http://47.x.x.x:8088/
2. 登录你开好的账号（默认 demo/123456，请在账号中枢改掉）
3. 点「上号模式」收集 → 再点「修改模式」
4. 手机 Shadowrocket：
   - 类型 SOCKS5
   - 服务器 = 云机公网IP
   - 端口 = 1080
   - 用户/密码 = 网页同一账号
5. Gateway 导出根证书，发到手机安装并信任（HTTPS MITM 需要）

【你（管理员）开号】
在云机打开 01_AccountServer.exe，添加账号密码即可。
用户用这对账号登录网页 + 连接代理。

【文件】
01_AccountServer.exe  账号中枢
02_Gateway.exe        流量网关
03_Engine.exe         引擎+网页
START_ALL.bat         一键启动
