水溶C · 打包
============

没有 Mac → 必看同目录「无Mac打包详解.txt」
（推 GitHub → Actions 点一下 → 下载 tipa）

有 Mac → 终端执行：
  cd Shuangji/Shuangji.iOS
  chmod +x package.sh && ./package.sh
产物：dist/水溶C.tipa

Windows 双击 package.cmd 会打开无 Mac 说明，不会本地编译。

装机推荐：TrollStore 装 tipa → 部署页「一键越狱并部署」（内置 Dopamine）→ 开游戏自动补丁。
打包默认会下载 Dopamine.tipa 打进包；小包可用 BUNDLE_DOPAMINE=0。
详见 README.md / 新手无Mac手把手.txt 第 12 章。
