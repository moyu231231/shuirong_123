============================================================
  水溶C · 完整使用教程（RootHide 越狱 + 自动补丁 + 双机）
============================================================

适用：TrollStore 已装好；设备可跑 RootHide Dopamine（或官方 Dopamine）
目标：一键部署后开游戏自动外部补丁，再用双机链路


------------------------------------------------------------
一、你需要准备什么
------------------------------------------------------------

【手机】
- 已安装 TrollStore（巨魔）
- 已安装最新「水溶C.tipa」（用本仓库打包出来的）
- 已装三角洲（com.tencent.tmgp.dfm）
- 小火箭 Shadowrocket（或同类）能连电脑代理

【电脑】
- 双机三件套已启动（顺序很重要）：
  1) AccountServer（账号，常见 9100）
  2) Engine（引擎/网页，常见 8088）
  3) Gateway（SOCKS5，常见 1080）
- 手机和电脑同一局域网，记下电脑 IP（如 192.168.1.8）
- 网页控制台：http://电脑IP:8088/ （以你实际端口为准）

【TrollStore 必开】
1. 打开 TrollStore → 设置
2. 打开「URL Scheme」
3. 点 Rebuild Icon Cache（重建图标缓存）
否则「一键越狱」唤不起安装界面。


------------------------------------------------------------
二、安装水溶C
------------------------------------------------------------

1. 把打包好的「水溶C.tipa」传到手机
2. 用 TrollStore 安装（打开 tipa 或在巨魔里选文件安装）
3. 桌面出现「水溶C」图标


------------------------------------------------------------
三、一键越狱并部署（推荐流程）
------------------------------------------------------------

1. 打开「水溶C」→ 底部「部署」

2. 「越狱版本」选：
   - RootHide Dopamine（推荐，打三角洲更合适）
   - 或官方 Dopamine（没有 RootHide 时）

3. 开关建议（先求稳）：
   - 自动外部内存补丁 = 开
   - 三角洲机型 tweak = 关（先别开）
   - settle 保持默认即可（约 45～55 秒）

4. 点「一键越狱并部署」
   - 若未装 Dopamine：会唤起 TrollStore，确认安装
   - 自动打开 Dopamine 后：在 Dopamine 里点「Jailbreak」，等成功
   - 水溶C 检测到越狱后会自动拷贝工具并拉起守护 sy_watch
   - 工具目录：/var/mobile/Library/shuiyong/

5. 部署成功后，「越狱状态」应显示：
   - RootHide 已越狱
   - 或 已越狱（rootless）

【RootHide 额外注意】
打开 RootHide Manager：
- 打三角洲时，不要把三角洲勾进「隐藏越狱」黑名单
  （否则机型 tweak 进不去；外部自动补丁一般仍可用）


------------------------------------------------------------
四、开游戏 → 看自动补丁是否生效
------------------------------------------------------------

1. 直接打开三角洲（不要先手动点「内存补丁」）

2. 水溶C → 「内存」页
   - 打开「自动刷新（3秒）」
   - 正常过程：
     a) 先变成 ⏳ WAIT settle pid=… time=新的时间
     b) 再变成 ✅ OK … flag=1 … time=更新后的时间

3. 同时看「守护：」那一行：
   - 要有 alive=1，且 time= 在变 → 守护活着
   - 没有心跳 / alive=0 → 点「重启自动守护 sy_watch」

4. 若一直是「旧 OK + 旧时间」：
   - 先开着游戏
   - 点「立即补丁（游戏需已打开）」
   - 成功后再看 time= 是否变新

【怎么判断成功】
- 必须看 flag=1（主效果：门闩/GOT）
- spoof≥1 只是改到了机型缓存串，可有可无
- jb=1 表示认到越狱环境
- time= 必须是刚才的新时间，旧时间=这次没补上


------------------------------------------------------------
五、双机链路（电脑改包）
------------------------------------------------------------

1. 确认电脑三件套都在跑，账号能登录网页

2. 手机小火箭：
   - 类型：SOCKS5
   - 服务器：电脑局域网 IP
   - 端口：Gateway 端口（常见 1080）
   - 用户/密码：账号中枢里的账号
   - 开启全局或按规则代理（游戏流量要走节点）
   - 需要 HTTPS 解密时：安装并「完全信任」网关根证书

3. 水溶C → 「链路」：
   - 填电脑 IP / 端口 / 账号密码
   - 连接成功后，按你的流程：
     · 读取（收集）
     · 大厅
     · 修改（局内）
   - 以网页控制台状态为准

4. 「状态 VPN」不是真正拦 ACE 包的主力；真正过滤靠小火箭 → Gateway。


------------------------------------------------------------
六、日常每次开机怎么用（最短版）
------------------------------------------------------------

1. 电脑开：Account → Engine → Gateway
2. 手机：若重启过，先打开 Dopamine 再 Jailbreak（半越狱）
3. 打开水溶C → 部署页看是否「已越狱」
   - 若守护可能掉了：内存页点「重启自动守护」
4. 小火箭连电脑节点
5. 开三角洲 → 内存页确认 OK + 新 time
6. 链路/网页切读取或修改


------------------------------------------------------------
七、各页按钮是干什么的
------------------------------------------------------------

【部署】
- 一键越狱并部署：装/开 Dopamine + 部署工具 + 拉起守护
- 仅部署补丁环境：已越狱时只部署工具/守护
- 仅重启守护 / 停止守护

【注入】（备用）
- 清理设备标识：清沙盒里 TSS/IDFV 等缓存（建议换号/异常时用）
- 内存补丁：手动补一次（守护失效时备用）
- 正常越狱自动流程下：不用每次点内存补丁

【内存】
- 刷新状态 / 自动刷新
- 立即补丁：游戏已开时马上补
- 重启自动守护

【链路】
- 连双机、模式切换（读取/大厅/修改等）


------------------------------------------------------------
八、可选：机型 tweak
------------------------------------------------------------

何时开：
- 外部改串 spoof 一直是 0，或你确认 ACE 在读实时 sysctl

怎么开：
1. 部署页打开「三角洲机型 tweak」
2. 再点一次「仅部署补丁环境」或一键部署
3. RootHide Manager 里确保三角洲未隐藏越狱
4. 重开游戏

注意：tweak 会多一个镜像，痕迹比纯外部补丁大。能只用 flag 就先别开。


------------------------------------------------------------
九、常见问题
------------------------------------------------------------

Q：内存页一直旧 OK？
A：守护没抓到游戏或没在跑。开游戏 →「立即补丁」；或「重启自动守护」后再进游戏。看心跳 alive=1。

Q：还要不要每次点内存补丁？
A：越狱部署成功且守护正常时，不用。手动补丁只是备用。

Q：RootHide 和官方 Dopamine 选哪个？
A：打三角洲优先 RootHide。官方也可，但路径/隐藏能力不同。

Q：一键越狱唤不起 TrollStore？
A：打开 URL Scheme + Rebuild Icon Cache。

Q：Dopamine Jailbreak 失败？
A：核对机型/系统是否在该版 Dopamine 支持列表；换对应 tipa；别混用未匹配的越狱包。

Q：flag=1 但仍异常？
A：补丁只挡一部分本地上报路径。必须小火箭真走 Gateway，网页模式正确；网络/65010 仍异常时查电脑网关与引擎，不是只靠手机补丁。

Q：换号/被画像？
A：注入页「清理设备标识」→ 再部署/补丁 → 再进游戏。
