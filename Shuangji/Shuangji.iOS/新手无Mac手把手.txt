============================================================
  水溶C · 没有 Mac · 新手手把手打包（从零开始）
============================================================

你要得到的最终文件：  水溶C.tipa
用什么安装：          手机上的 TrollStore（巨魔）
本机需要什么：        一台 Windows 电脑 + 浏览器 + 网络
不需要：              Mac、Xcode、苹果开发者账号


------------------------------------------------------------
第 0 章：先搞懂在干什么（1 分钟）
------------------------------------------------------------

苹果规定：编 iPhone 软件必须用 Mac。
你没有 Mac，所以我们用 GitHub 网站上「免费的云端 Mac」帮你编。

流程就四句：
  1. 把电脑上的代码放到 GitHub（网上仓库）
  2. 在网页上点一下「开始打包」
  3. 等它跑完，下载一个 zip
  4. 解压得到 tipa，传到手机用巨魔安装

下面按「完全没接触过 GitHub」来写。


------------------------------------------------------------
第 1 章：注册 GitHub（没有账号才做）
------------------------------------------------------------

1. 打开浏览器，访问：
   https://github.com/signup

2. 用邮箱注册，设置密码，验证邮箱。

3. 登录成功后，右上角应能看到你的头像。

【注意】
- 用户名以后会用到，例如 ZhangSan
- 仓库地址会像：https://github.com/ZhangSan/shuiyong


------------------------------------------------------------
第 2 章：在 GitHub 新建一个空仓库
------------------------------------------------------------

1. 登录后，点右上角 「+」
2. 点 「New repository」（新建仓库）
3. 填写：
   - Repository name（仓库名）：随便，例如  shuiyong
   - 选 Public（公开）——新手更省事，私有也可以
4. 【重要】下面这些都不要勾：
   - Add a README file        ← 不要勾
   - Add .gitignore           ← 不要勾
   - Choose a license         ← 不要勾
5. 点绿色按钮 「Create repository」

6. 创建成功后，页面会显示仓库地址，类似：
   https://github.com/你的用户名/shuiyong.git
   把这一行复制到记事本，后面要用。


------------------------------------------------------------
第 3 章：安装 Git（Windows）
------------------------------------------------------------

1. 打开：
   https://git-scm.com/download/win

2. 下载并安装。一路「Next」即可。
   （遇到选项保持默认就行）

3. 安装完后：
   - 按键盘 Win 键
   - 输入：Git Bash
   - 打开 「Git Bash」黑色窗口

4. 在窗口里输入下面两行（换成你自己的，只要一次）：

   git config --global user.name "你的名字"
   git config --global user.email "你的邮箱@xx.com"

   每输完一行按回车。


------------------------------------------------------------
第 4 章：把桌面上的工程推到 GitHub
------------------------------------------------------------

你的工程文件夹是：
  C:\Users\Administrator\Desktop\WinsockPacketEditor-master

【4.1 打开 Git Bash，进入工程目录】

复制粘贴下面整行，回车：

  cd /c/Users/Administrator/Desktop/WinsockPacketEditor-master

如果提示 No such file，说明路径不对，到资源管理器看桌面文件夹真实名字。


【4.2 看是不是已经有 git】

输入：

  git status

你这台电脑上的工程一般已经是 git 仓库，会列出很多文件。
若提示 not a git repository，再执行：

  git init


【4.3 添加远程地址】

（你当前还没有绑定 GitHub，必须做这一步）

把地址换成你第 2 章记事本里的：

  git remote remove origin
  git remote add origin https://github.com/你的用户名/shuiyong.git

第一行如果提示没有 origin，忽略，继续第二行。


【4.4 提交并上传】

你本地默认分支名多半是 master（不是 main），按下面做：

  git add Shuangji/Shuangji.iOS
  git add .github/workflows/shuiyong-tipa.yml
  git commit -m "shuiyong ios package"
  git push -u origin master

若你想用 main 这个名字，也可以：

  git branch -M main
  git push -u origin main

【说明】
第一次提交如果提示 nothing to commit，先确认 add 有没有成功：
  git status
应看到绿色的要提交文件；没有的话把路径抄错了。
【第一次 push 会弹登录】
- 浏览器打开 GitHub 登录授权，或
- 让你输入用户名/密码：密码处请用 GitHub「Personal Access Token」
  （不是登录密码）

如何做 Token（若需要）：
  1. GitHub 网页 → 右上角头像 → Settings
  2. 左侧最下面 Developer settings
  3. Personal access tokens → Tokens (classic)
  4. Generate new token (classic)
  5. Note 随便写；勾选 repo
  6. Generate → 复制那一长串（只显示一次）
  7. git push 要密码时，粘贴这串 Token

【成功标志】
浏览器打开你的仓库页面，能看到文件夹，
其中有：
  Shuangji/Shuangji.iOS/
  .github/workflows/shuiyong-tipa.yml


------------------------------------------------------------
第 5 章：打开 Actions 权限（有时默认关着）
------------------------------------------------------------

1. 打开你的仓库网页
2. 点上面 「Settings」（设置）
3. 左侧 「Actions」→「General」
4. 在 Actions permissions 里选：
   Allow all actions and reusable workflows
5. 拉到最下 Save


------------------------------------------------------------
第 6 章：点一下开始打包（最关键）
------------------------------------------------------------

1. 仓库顶栏点 「Actions」
   （和 Code、Issues 同一排）

2. 如果中间有大按钮 「I understand my workflows, go ahead and enable them」
   → 先点它启用

3. 左侧工作流列表里点：
   「水溶C tipa」

4. 右侧看到 「Run workflow」按钮
   - 点它
   - Branch 选 main（或你的默认分支）
   - 再点绿色 「Run workflow」

5. 刷新页面，上面会出现一条正在跑的任务
   - 黄色圆点 / 转圈 = 正在跑
   - 绿色勾 = 成功
   - 红色叉 = 失败（看第 9 章）

6. 一般要等 5～20 分钟。第一次更久。
   可以离开，过会儿再回来看。


------------------------------------------------------------
第 7 章：下载 tipa
------------------------------------------------------------

1. 点进那次已经成功的运行记录（绿色勾那条）

2. 拉到页面最下面，找到 「Artifacts」

3. 点 「shuiyong-tipa」下载（是一个 zip）

4. 下载到电脑后，右键 → 解压

5. 解压后应看到类似：
     水溶C.tipa
   这就是安装包。


【找不到 Artifacts？】
- 确认任务是绿色成功，不是红色失败
- 在运行摘要页往下滚，有时在最底部
- 用手机浏览器可能显示不全，请用电脑 Chrome


------------------------------------------------------------
第 8 章：装到 iPhone（仍然不需要 Mac）
------------------------------------------------------------

前提：手机已经装好 TrollStore（巨魔）。
若还没装巨魔，需要先按你系统版本去装 TrollStore（这是另一套教程）。

【把 tipa 弄进手机，任选一种】
A) 隔空投送 / 微信文件传输助手 / QQ
B) 网盘：上传 tipa → 手机下载
C) 爱思助手 / 3uTools 线传文件

【安装】
1. 手机打开 TrollStore
2. 点右上角 + 或「安装」
3. 选中 水溶C.tipa
4. 等安装完成，桌面出现「水溶C」

【之后怎么用（简版）】
1. 电脑打开双机软件（水溶C端口 / Shuangji），同一 WiFi
2. 手机打开「水溶C」
3. 「注入」页：选游戏 → 点注入 → 杀掉游戏重开
4. 「链路」页：填电脑 IP、账号密码 → 连接
5. 模式：读取 → 大厅 → 局内


------------------------------------------------------------
第 9 章：失败了怎么办（对照查）
------------------------------------------------------------

【git push 被拒绝 / 403】
- Token 权限要勾 repo
- 远程地址用户名是否写错

【Actions 里没有「水溶C tipa」】
- 确认 .github/workflows/shuiyong-tipa.yml 已经在仓库里
- 刷新页面；分支是否 push 成功

【Run workflow 是灰的】
- 完成第 5 章打开 Actions 权限
- 先点 Enable workflows

【打包红色失败】
1. 点进失败那次
2. 点红色的 Package 或 Tools 那一步
3. 把最后 30 行错误复制下来（可发给会的人看）
4. 常见：网络装 brew 超时 → 再点一次 Run workflow 即可

【Artifacts 过期】
- GitHub 默认产物只保留几天
- 过期了重新点一次 Run workflow 再下


------------------------------------------------------------
第 10 章：以后改了代码怎么再打包
------------------------------------------------------------

每次改完 iOS 相关代码：

  cd /c/Users/Administrator/Desktop/WinsockPacketEditor-master
  git add -A
  git commit -m "update"
  git push

然后重复第 6～7 章：Actions → Run → 下载新 tipa。
