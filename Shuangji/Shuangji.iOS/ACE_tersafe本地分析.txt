================================================================
一、先把话说死（为什么你会觉得我“糊弄”）
================================================================
1) 本机「状态 VPN」不劫持默认路由 → 根本不拦任何包。连上只是状态栏图标。
2) 只改 GOT / 少量导出 → 只挡「游戏经导入表调用」的路径。
   tersafe 内部 BL → COREREPORT → send_cs/send_gs 完全不受影响。
3) ACE/TSS 是「行为+上报+服务端画像」，不是「改一个函数就无敌」。
   专精仓库共识：单点 RET 过不了；要杀扫描器注册 / TDM / 杀进程路径 / 上报通道 多层。

所以：补丁“成功”≠过检。过检要同时切断「检测结果产生」和「结果送出」。

结论（对 iOS 这颗 so）：
  A. 举报/异常 ≠ 只有 4013。至少 send_cs（CS/65010）+ send_gs（游戏服回调）。
  B. 改 TEXT 会撞 bin_patch / inline_hook_opcode_dismatch → 闪退或加风险分。
  C. 匿名可执行页 / 新 dylib → vm_region 扫得到。
  D. 真正该打的枢纽是：COREREPORT / TDM / send 路径 / OnRecv；
     以及「别让扫描器先记一笔再上报」。

五、按 ACE 专精仓库对齐后的正确优先级（iOS）
================================================================
P0 上报出不去（否则扫到了一定会画像）
  · 云端 Gateway 修改模式拦 65010/4013（send_cs）
  · 内存侧打断 COREREPORT / get_report 取数 / send_gs 回调
  · 小火箭必须真走网关，不是状态 VPN

P1 检测结果少产生（搞事时基础检测）
  · OnRecv / rcv_anti_data 空掉（少吃检测任务）
  · 尽量不留：匿名 RX、新 dylib 名、磁盘 LC、过多 TEXT 补丁
  · 参考 Android：杀 scanner 注册 / 关 TDM 开关 —— iOS 需在 so 里找等价全局量

P2 别被自杀
  · 不碰 0x10E36C 总闸瞎 RET（已验证易崩）
  · TEXT 补丁前校验 prologue；版本不对就跳过

P3 长期
  · 用 IDA 在本地 tersafe 定位：
      tdm_report / COREREPORT 提交函数
      g_tdm 类开关（对照 ACE-ANTICHEAT Tier2）
      send_gs 回调槽（tss_sdk_send_data_to_svr）
      MRPCS FastScanThread 启动点

六、下一步建议（别再瞎加开关）
================================================================
1. 服务器确认：Account:9100 + Gateway:1080 + Engine「修改」都在跑
2. 手机：小火箭导入节点并全局代理（不要只靠 App 里状态 VPN）
3. 内存补丁后看 status：要有 recv>0 或 leaf>0；got 可为 0
4. 若仍秒检：把「是进游戏就踢 / 进局踢 / 延迟踢」说清 + 抓一局上行 send dump
   用来对 send_gs 特征（目前最大缺口）

七、把 Android ACE 8 层映射到我们这颗 iOS tersafe
================================================================
Android (ACE-ANTICHEAT)          |  iOS tersafe (本机实测)
---------------------------------+--------------------------------
ace_register_scanner_module      |  MRPCS CFastScanThread / 扫描器注册
                                 |  （字符串有 RTTI，函数未导出）
g_tdm_report_enabled 两字节      |  DATA/BSS 里同类开关（需 xref tdm_report）
ace_submit_corereport            |  COREREPORT @内部 0x3F284 + 串 0x286D28
                                 |  REMOTECONFIG @ 0x286D3F（同簇）
AnoSDK getreport / delreport     |  导出 TssSDKGetReportData@0xF9A7C 等
senddatatosdk / OnRecv           |  TssSDKOnRecvData@0xF9AB4
                                 |  tss_sdk_rcv_anti_data@0x1BA9C
senddatatosvr (GS 夹带)          |  tss_sdk_send_data_to_svr 串@0x289AA9
                                 |  + send_cs/send_gs 计数串
ConfigUpdateFromServer           |  DoConnCSChannel + REMOTECONFIG
VM / inline relocator            |  bin_patch_cnt / inline_hook_opcode_dismatch
RWX / maps 扫描                  |  @_vm_region_64 / mach_vm_region_recurse

专精仓库真正在做的是「多层同时关」；
我们现在大约只覆盖了他们的 Tier2 半截（COREREPORT TEXT）+ OnRecv，
缺 Tier1（扫器注册）和 DATA 开关，以及 GS 出口。

TEXT 里现成 ret0 小工具有 37 处（MOV X0,#0; RET）——GOT 改写应优先用 so 内 gadget，
不一定非要去系统库找。
