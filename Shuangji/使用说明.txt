# 双机 Shuangji 使用说明

三件套必须一起用，启动顺序如下。

## 软件列表

| 文件 | 作用 | 默认端口 |
|------|------|----------|
| `01_AccountServer.exe` | 账号中枢（开号/鉴权，类似 CCProxy） | 9100 |
| `02_Gateway.exe` | 流量网关（SOCKS5 + HTTPS MITM，类似 Charles） | 1080 |
| `03_Engine.exe` | 数据处理引擎 + 网页控制台 | API 9200 / 网页 8088 |

数据目录：`C:\ProgramData\Shuangji\`

---

## 启动顺序（重要）

1. **管理员运行** `01_AccountServer.exe`（先开账号服务）
2. **管理员运行** `03_Engine.exe`（引擎依赖账号鉴权）
3. **管理员运行** `02_Gateway.exe`（网关依赖前两者）

默认演示账号：`demo` / `123456`（可在账号中枢里改/新增）

---

## 网页控制台

浏览器打开：http://127.0.0.1:8088/

1. 用账号中枢里的账号密码登录  
2. 点 **上号模式（收集）** → 专属数据池开始收集校验相关包  
3. 点 **修改模式** → 自动保存池，之后同账号新包按池改校验（含兜底，不放行未处理 01 包）  
4. 换号或下次使用前点 **重置数据池** → 清空旧池，再重新上号收集  

---

## iPhone / TrollStore（水溶C）

打包看 `Shuangji.iOS/打包.txt`（推荐 GitHub Actions 出 tipa，Windows 不用装 Xcode）。

```
注入 → 选游戏 → 注入
链路 → 填双机 IP/账号 → 连接 → 读取/大厅/局内
```

1. TrollStore 安装 `水溶C.tipa`  
2. Gateway 导出根证书 → 手机完全信任  
3. 注入游戏并重开  
4. 链路连双机  



## iPhone / Shadowrocket（仅第2层）

1. 电脑与手机同一局域网，记下电脑 IP（如 `192.168.1.8`）  
2. 在 Gateway 点 **导出根证书给手机**，把桌面的 `shuangji-ca.cer` 发到手机  
3. iOS：安装描述文件 → 设置 → 通用 → 关于本机 → **证书信任设置** → 启用完全信任  
4. Shadowrocket 添加节点：  
   - 类型：`SOCKS5`  
   - 服务器：电脑 IP  
   - 端口：`1080`  
   - 用户：账号中枢账号  
   - 密码：对应密码  
5. 开启代理，跑业务流量；Engine 日志 / 网页池列表应有数据  


---

## 推荐操作流（一次完整上号）

```
开三个软件
 → 网页登录账号
 → 上号模式
 → 手机连上跑一会儿（收集）
 → 网页看池条数增加
 → 改成「修改模式」
 → 继续跑，观察修改次数增加
 → 下次换号前先「重置」
```

---

## 防火墙

首次运行若提示防火墙，请允许：`1080 / 8088 / 9100 / 9200` 的入站访问。

HttpListener 绑 `http://+:端口/` 失败时会自动回退到 `127.0.0.1`（仅本机）。要给手机用，请用管理员运行并放行防火墙。

---

## 说明

- Gateway 对 443 默认开启 MITM；未信任根证书时会回退透传（此时 HTTPS 内容不可改）。  
- 数据池按账号隔离；修改模式使用「本账号本次收集」的新鲜数据。  
- 本套件为代理链路上的收包/改包工作台，不是游戏进程注入版 WPE。
